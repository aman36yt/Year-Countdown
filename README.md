# 🎉 Year Countdown Web App

A dynamic countdown web app that displays the remaining time until the New Year 🎆

---

## ✨ Features

⏳ Live countdown timer (days, hours, minutes, seconds)
🎯 Updates in real-time every second
📱 Responsive design for all devices
🎨 Clean and minimal UI
⚡ Lightweight and fast

---

## 🛠️ Tech Stack

* 🧱 HTML5 – Structure
* 🎨 CSS3 – Styling
* ⚡ JavaScript – Countdown logic

---

## ⚙️ How It Works

* The app calculates the time remaining until the next New Year
* JavaScript updates the countdown every second
* Displays time in:

  * Days
  * Hours
  * Minutes
  * Seconds
